📖 Run All 14 Tests Suite Developer Guide

Complete technical specification of the 1 Live AWS Ping (us-east-2) + 14 Client-Side Contract Invariant Checks, dynamic Lambda Request IDs, verifiable upstream GitHub resources, and live individual application executions.
⚡ 1. Suite Execution Architecture (Live Cloud Ping + Invariants)

The Run All 14 Tests Suite balances live cloud verification with deterministic client-side contract assertion:

  • 1 Real AWS Network Call: Whenever executed in Owner Mode, the suite dispatches an HTTPS POST request across the internet to the protected AWS Lambda Function URL in region us-east-2. It measures live network latency and displays the real, unique x-amzn-RequestId issued by AWS on every pass.
  • Dynamic Step Functions Execution: The live ping triggers a real AWS Step Functions execution (cosmos-cicd-ai-pipeline-sfn) and Amazon S3 artifact write in us-east-2, returning a timestamped execution ID linked to the AWS Step Functions Console.
  • 14 In-Browser Architectural Invariants: Rather than incurring unpredictable network jitter across 14 consecutive cloud round trips (which would take ~35 seconds), the runner evaluates each application's architectural contracts locally, guaranteeing instantaneous feedback and zero bill runaway.
  • Explicit Fixed vs. Live Labeling: Upstream static references are explicitly tagged as [LAST PUSH], [ISOLATED], or [LATEST CI RUN] so they are never conflated with live execution artifacts.

☁️ 4. Live Cloud Operations in Individual Test Applications

While the Run All suite asserts contract invariants, the individual standalone applications execute live cloud workloads in AWS and GitHub:

  • Test 1 (Git Push Origin): Dispatches real Git-over-SSH push from AWS Lambda in us-east-2 to GitHub, creating verified commits (#0827926 ↗ and #f364d8a ↗, both HTTP 200 OK).
  • Test 7 (Forward Push Trigger): Executes cosmos-cicd-ai-pipeline-sfn in AWS Step Functions (region us-east-2) and surfaces the direct AWS Console execution URL.
  • Test 9 (Cloud Receipt Return): Stores deployment receipts in Amazon S3 (s3://cosmos-ai-factory-cicd-artifacts/deployments/) with KMS signatures and Content-MD5 validation.
  • Test 12 (Amazon S3): Performs bit-for-bit SHA-256 and MD5 upload and download verification for clean and perturbed payloads.
